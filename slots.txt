# The call table: numbered sockets through which one piece reaches another. A number, once given, is never
# reused for something else (like a system call number). The host keeps each socket pointing at the current
# implementation; a piece calls through the table it is handed and never holds an address of its own.
# Sockets 0-255 are code. Sockets 256-511 are HANDLES: each holds the address of a block of memory the host owns
# (a picture today; files and fonts later), or nothing. A piece given handle h reads socket 256 + h, and must
# check what it finds there before using it. The host fills and empties handles; pieces never do.
# <slot> <piece> <entry>
